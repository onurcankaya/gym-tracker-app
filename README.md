## Gym Tracker App

```bash
# Install packages
npm install
```

```bash
# Run dev server
npm run dev
```

### Running Tests

This project uses Vitest for unit testing.

```bash
# Run tests
npm test

# Run tests in watch mode
npm test -- --watch

# Run tests with coverage
npm test -- --coverage
```

**Test Coverage:**

- Model layer (database operations)
- Service layer (business logic and validation)
- Edge cases and error handling
